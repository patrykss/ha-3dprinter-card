# Changelog

## 1.0.0

- Initial release of `ha-3dprinter-card` and `ha-3dprinter-card-mini`.
- Visual editors for both cards.
- Entity/service based support for different printer integrations.
- Offline printer illustrations and custom SVG support.
- Ten UI languages.
- Configurable sections, action buttons, Todo list and per-card theme variables.
- Per-row visibility controls and SVG file upload in the visual editor.
- Added repository validation workflow for HACS / Marketplace.
